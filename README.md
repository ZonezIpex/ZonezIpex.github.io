## About Me

브랜드 메시지를 효과적으로 전달하는 콘텐츠를 기획하고 제작하는  
**디지털 콘텐츠 마케터 신민수**입니다.

단순히 보기 좋은 결과물을 만드는 데 그치지 않고,  
**타겟에 맞는 메시지 설계 / 비주얼 구성 / 사용자 흐름 이해**를 바탕으로  
콘텐츠가 실제 성과로 이어지도록 고민합니다.

기존의 웹 퍼블리싱 경험은 현재  
**랜딩페이지 이해도, 개발 협업, 콘텐츠 실행력**으로 연결되고 있습니다.

---

## What I Do

- **Content Planning**  
  타겟과 목적에 맞는 콘텐츠 주제, 구조, 메시지를 기획합니다.

- **Visual Content Design**  
  브랜드 톤앤매너에 맞는 이미지, 상세페이지, 썸네일, 홍보 콘텐츠를 제작합니다.

- **Technical-Based Marketing**  
  SEO, 랜딩페이지 구조, 사용자 흐름에 대한 이해를 바탕으로  
  더 효율적인 콘텐츠 운영 방향을 설계합니다.

- **Communication & Collaboration**  
  디자인, 기획, 개발 관점을 함께 이해하며 협업할 수 있습니다.
