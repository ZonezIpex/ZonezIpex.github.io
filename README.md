## About Me

브랜드와 서비스의 핵심 메시지를  
전달력 있는 콘텐츠로 기획하고 제작하는 **콘텐츠 마케터 신민수**입니다.

단순히 보기 좋은 결과물에 그치지 않고,  
**무엇을 어떻게 보여줘야 하는지**를 고민하며  
포스터, 아이콘, 소개자료, 웹 화면 등 다양한 형식으로 메시지를 정리합니다.

기존의 웹 퍼블리싱 경험은  
현재 **화면 구조 이해, 랜딩 흐름 파악, 개발 협업 커뮤니케이션**의 강점으로 이어지고 있습니다.

---

## What I Do

- **콘텐츠 기획**  
  프로젝트 목적과 타겟에 맞게 콘텐츠 주제, 메시지, 구성 방식을 설계합니다.

- **브랜딩 콘텐츠 제작**  
  로고, 포스터, 썸네일, 서비스 소개형 비주얼 등 브랜드와 프로젝트를 설명하는 콘텐츠를 제작합니다.

- **시각적 커뮤니케이션**  
  복잡한 정보도 한눈에 이해할 수 있도록 화면과 비주얼 중심으로 정리합니다.

- **협업 기반 실행**  
  기획, 디자인, 개발 흐름을 함께 이해하며 팀 프로젝트 안에서 유연하게 협업합니다.
