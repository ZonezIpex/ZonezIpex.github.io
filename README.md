## About Me

서비스와 브랜드의 핵심 메시지를  
보기 쉬운 콘텐츠로 정리하고 전달하는 **콘텐츠 마케터 신민수**입니다.

단순히 시각적으로 예쁜 작업물에 그치지 않고,  
**프로젝트의 목적 / 사용자에게 전달할 포인트 / 화면에서의 보여지는 방식**까지 함께 고민합니다.

기존의 웹 퍼블리싱 경험은  
현재 **랜딩 구조 이해, 화면 흐름 파악, 개발 협업 커뮤니케이션**의 강점으로 이어지고 있습니다.

---

## Focus

- **Content Planning**  
  프로젝트 목적에 맞는 주제와 메시지를 정리하고 콘텐츠 구조를 기획합니다.

- **Branding & Promotion Design**  
  로고, 포스터, 상세페이지형 콘텐츠, 썸네일 등 브랜드와 서비스 인지에 필요한 비주얼을 제작합니다.

- **Visual Communication**  
  복잡한 서비스 내용도 한눈에 이해될 수 있도록 시각적으로 구성합니다.

- **Collaboration**  
  기획, 디자인, 개발 흐름을 함께 이해하며 팀 프로젝트 안에서 유연하게 협업합니다.
