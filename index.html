소개
안녕하세요. 게임 시스템과 웹 개발의 구조적 흐름에 관심을 가지며 성장해 온 신민수입니다.

마인크래프트·스타크래프트의 명령어 구조를 따라 해보던 초등학생 시절부터, 사용자가 어떻게 서비스를 경험하는지를 늘 고민해왔습니다. 대학에서는 React 기반의 웹 개발과 2D 게임 개발 프로젝트를 통해 기획–구현–디버깅 전 과정을 경험하며 자연스럽게 사용자 중심의 개발 관점을 갖게 되었습니다.

제가 만든 기능이 실제로 동작하고, 유저 반응을 보고 개선하는 과정에서 “사용자 경험을 개선하는 개발자”라는 목표를 갖게 되었고, 이는 지금도 꾸준히 개발을 공부하는 원동력이 되고 있습니다.
성장 과정
초등학교 때 게임 속 구조가 궁금해 직접 명령어를 타이핑해보며 프로그래밍에 관심을 갖기 시작했습니다.

중·고등학교에서는 JavaScript로 간단한 2D 도트 게임을 제작하며 기초를 다졌고, 대학에서는 웹 페이지 및 2D 게임 프로젝트를 통해 협업, 문제 해결 능력, UI 설계 등 실전적인 경험을 쌓았습니다.

단순히 재미로 시작했던 관심이 사용자 경험을 고민하는 개발자로 성장하게 만든 기반이 되었습니다.
지원 동기
다양한 게임을 하면서 자연스럽게 “유저가 어떤 시점에서 불편함을 느낄까?”를 관찰하게 되었고, 프로젝트 경험을 통해 겉으로 보이는 화면보다 내부 시스템의 안정성이 사용자 경험을 결정한다는 점을 깊이 깨달았습니다.

특히 주간 모니터링 직무는 단순한 문제 확인이 아니라 유저 입장에서 불편을 해석하고 원인을 분석하는 역할이라고 이해하고 있습니다.

제가 가진 관찰력과 문제 해결 경험은 이 업무에 적합하다고 생각합니다.
사회경험 및 강점
학과 프로젝트를 진행할 때, 팀원의 부재나 예기치 못한 문제로 개발이 지연된 경험이 많았습니다. 그럴 때마다 대신 해주는 것이 아니라 모르는 부분을 직접 설명하며 함께 해결해 나갔습니다.

이 경험을 통해 남탓을 하지 않고 팀 전체의 완성도를 끌어올리는 방식으로 문제를 해결하는 법을 배웠습니다. 또한 팀장을 맡아 프로젝트를 주도한 경험 덕분에 소통 능력과 조율 능력도 자연스럽게 향상되었습니다.
