소개

시맨틱 마크업과 반응형 레이아웃으로 화면의 구조를 먼저 잡고, 접근성과 일관된 UI 규칙으로 퍼블리싱 품질을 맞춥니다. GTQ 포토샵·일러스트 기반으로 UI 구성요소를 제작해 실제 서비스 화면에 자연스럽게 적용합니다.

성장 과정

JavaScript/React 프로젝트를 통해 화면 설계→구현 과정을 반복하며, 컴포넌트 단위로 스타일/레이아웃을 안정적으로 맞추는 경험을 쌓았습니다. GTQ 기반 리소스 제작(포토샵·일러스트)과 퍼블리싱 디테일(간격·정렬·상호작용)을 함께 강화해 왔습니다.
