소개
안녕하세요. 게임 시스템과 웹 개발의 구조적 흐름에 관심을 가지고 꾸준히 성장해온 신민수입니다.

마인크래프트·스타크래프트의 명령어 구조를 따라 해보던 어린 시절부터 사용자가 어떤 경험을 하게 되는지를 늘 고민해왔습니다.

대학에서는 React 기반 웹 서비스와 2D 게임 개발 프로젝트를 진행하며 기획–구현–디버깅까지 개발의 전체 흐름을 직접 경험했습니다.

이러한 과정 속에서 “사용자 경험을 개선하는 개발자”라는 목표를 갖게 되었습니다.
성장 과정
초등학교 때 게임 속 구조가 궁금해 명령어를 직접 따라 해보며 프로그래밍을 접하게 되었습니다.

중·고등학교에서는 JavaScript로 2D 도트 게임을 제작하며 기초를 잡았고, 대학에서는 웹서비스와 게임 프로젝트를 수행하며 협업 능력과 문제 해결 능력을 키웠습니다.

단순한 흥미가 아니라, 사용자가 편하게 즐길 수 있는 기술을 만들고 싶다는 개발자로서의 방향성을 갖게 되었습니다.
