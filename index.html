소개

사용자 흐름을 먼저 설계하고, 일관된 UI로 화면을 정리합니다. GTQ 포토샵·일러스트 기반으로 UI 요소를 제작하며, 실제 서비스 화면에 자연스럽게 녹이는 데 집중합니다.

성장 과정

JavaScript/React 팀 프로젝트로 화면 설계→구현까지 반복해 왔습니다. GTQ 포토샵·일러스트를 준비하며 컴포넌트용 UI 리소스를 직접 제작하고 품질 기준을 맞추는 연습을 하고 있습니다.
